สมุดเงินโรงเรียน โดย PEHPEH · มีผลตั้งแต่วันที่ 3 พฤศจิกายน 2569

สมุดเงินโรงเรียน ("ระบบ") เป็นระบบการเงินโรงเรียนที่ทำงานบน Google Sheet และ Google Apps Script ในบัญชี Google ของโรงเรียนเอง นโยบายนี้อธิบายว่าผู้ให้บริการ (PEHPEH) เข้าถึงและเก็บข้อมูลอะไรบ้าง

1. ข้อมูลการเงินของโรงเรียน

  • ข้อมูลการเงิน ทะเบียนคุม เอกสาร รายชื่อผู้ใช้ และไฟล์แนบทั้งหมด เก็บอยู่ใน Google Sheet และ Google Drive ของโรงเรียนเท่านั้น
  • ผู้ให้บริการไม่มีสิทธิ์เข้าถึงไฟล์ของโรงเรียน ไม่คัดลอก ไม่เก็บสำรอง และไม่ส่งข้อมูลเหล่านี้ไปที่ใด
  • โรงเรียนเป็นผู้ควบคุมข้อมูลส่วนบุคคลที่บันทึกในระบบ (เช่น ชื่อครู ผู้รับเงิน) ตามพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล พ.ศ. 2562

2. ตัวติดตั้งของระบบ และสิทธิ์ที่ขอจากบัญชี Google

ตัวติดตั้ง (หน้า "ติดตั้ง / อัปเดต สมุดเงินโรงเรียน") ทำงานในนามบัญชี Google ของผู้ที่กดติดตั้ง และขอสิทธิ์ต่อไปนี้

  • ดูและจัดการโปรเจกต์ Apps Script (script.projects): ใช้ใส่โค้ดรุ่นล่าสุดลงในโปรเจกต์สคริปต์ของชีตโรงเรียน และสร้างโปรเจกต์หน้าลงทะเบียนครูใน Drive ของโรงเรียน ระบบแก้เฉพาะโปรเจกต์ที่ผู้ใช้เปิดตัวติดตั้งจากชีตนั้น และไม่อ่านหรือแก้โปรเจกต์อื่นของผู้ใช้
  • จัดการการเผยแพร่ (deployment) ของ Apps Script (script.deployments): ใช้สร้างและอัปเดตลิงค์เว็บของโรงเรียน
  • เชื่อมต่อบริการภายนอก (script.external_request): ใช้เรียก Google Apps Script API เพื่อทำ 2 ข้อข้างต้น
  • อีเมลของบัญชี (userinfo.email): ใช้ระบุสิทธิ์การใช้งาน (ทดลองใช้ รายปี ซื้อขาด) ของผู้ติดตั้ง

ตัวติดตั้งไม่อ่านข้อมูลในชีต ไม่อ่านไฟล์ใน Drive และไม่ส่งข้อมูลจาก Google ไปให้บุคคลอื่น

3. ข้อมูลที่ผู้ให้บริการเก็บ

เมื่อมีการติดตั้งหรืออัปเดต ผู้ให้บริการเก็บข้อมูลต่อไปนี้ในระบบของตัวติดตั้ง เพื่อจัดการสิทธิ์และช่วยเหลือการใช้งาน

  • อีเมลบัญชี Google ของผู้ติดตั้ง
  • ชื่อโรงเรียนที่ผู้ติดตั้งกรอก
  • รหัสโปรเจกต์สคริปต์ที่ติดตั้ง
  • แบบสิทธิ์ วันหมดอายุ วันที่ติดตั้งล่าสุด และรุ่นของระบบ
  • ข้อมูลการชำระเงินและการติดต่อที่โรงเรียนส่งมาเอง (เช่น หลักฐานการโอน)

ข้อมูลเหล่านี้ใช้เพื่อเปิดสิทธิ์ ต่ออายุ ออกใบเสร็จ และติดต่อเรื่องการใช้งานเท่านั้น ไม่ขาย ไม่ให้เช่า และไม่ใช้เพื่อโฆษณา

4. การใช้ข้อมูลจาก Google API

การใช้และการส่งต่อข้อมูลที่ได้รับจาก Google API เป็นไปตาม Google API Services User Data Policy รวมถึงข้อกำหนด Limited Use

5. LINE และอีเมลแจ้งเตือน

ถ้าโรงเรียนเปิดใช้การแจ้งเตือนทาง LINE ระบบใช้ LINE Official Account ของโรงเรียนเอง รหัสผู้ใช้ LINE ที่ผูกไว้เก็บในโปรเจกต์ของโรงเรียน อีเมลแจ้งเตือนส่งจากบัญชี Google ของโรงเรียน ผู้ให้บริการไม่ได้รับข้อมูลเหล่านี้

6. ระยะเวลาเก็บและการขอลบ

ผู้ให้บริการเก็บข้อมูลในข้อ 3 ตลอดช่วงที่โรงเรียนใช้บริการ และไม่เกิน 2 ปีหลังสิทธิ์สิ้นสุด โรงเรียนขอดู แก้ไข หรือลบข้อมูลได้ทางอีเมลด้านล่าง และถอนสิทธิ์ที่ให้ตัวติดตั้งได้ทุกเมื่อที่ myaccount.google.com/permissions เว็บที่ติดตั้งไว้แล้วยังใช้ต่อได้

7. การเปลี่ยนแปลงนโยบาย

ถ้ามีการเปลี่ยนแปลง ผู้ให้บริการจะแก้วันที่มีผลในหน้านี้ และแจ้งโรงเรียนที่ใช้บริการอยู่
