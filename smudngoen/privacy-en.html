Privacy Policy

Smudngoen ("สมุดเงินโรงเรียน", School Finance Book) by PEHPEH · Effective 3 November 2026 (B.E. 2569) · ฉบับภาษาไทย

Smudngoen (the "System") is a school finance ledger that runs on Google Sheets and Google Apps Script inside the school's own Google account. This policy explains what the provider (PEHPEH) can access and what it stores. If this English version and the Thai version differ, the Thai version applies.

1. The school's financial data

  • All financial records, registers, documents, user lists and attachments are stored only in the school's own Google Sheet and Google Drive.
  • The provider has no access to the school's files. It does not copy, back up or transmit this data anywhere.
  • The school is the data controller for any personal data recorded in the System (for example teacher or payee names) under Thailand's Personal Data Protection Act B.E. 2562 (2019).

2. The installer and the Google permissions it requests

The installer (the "สมุดเงินโรงเรียน ตัวติดตั้ง" page) runs as the Google account of the person who installs, and requests these permissions:

  • View and manage Apps Script projects (script.projects): to write the latest System code into the Apps Script project bound to the school's sheet, and to create a teacher sign-up project in the school's Drive. The installer only changes the project of the sheet it was opened from (and the sign-up project it created). It does not read or change the user's other projects.
  • Manage Apps Script deployments (script.deployments): to create and update the school's web app links.
  • Connect to an external service (script.external_request): to call the Google Apps Script API for the two items above, and, only if the school chooses a short link name, to save that short link on officialpehpeh.com (see section 3).
  • See your email address (userinfo.email): to identify the installer's licence (trial, yearly or lifetime).

The installer does not read data in the sheet, does not read files in Drive, and does not share data obtained from Google with anyone else.

3. Data the provider stores

When the System is installed or updated, the provider stores the following in the installer, to manage licences and provide support:

  • The installer's Google account email address
  • The school name entered by the installer
  • The ID of the installed Apps Script project
  • Licence type, expiry date, last install date and System version
  • If the school chooses a short link name: that name and the school's web app link. The short link is published at officialpehpeh.com/s/<name> so teachers can open it, which means anyone with the link can reach the school's sign-in page. The web app still requires a Google account that the school has added as a user.
  • Payment and contact details that the school sends itself (for example a transfer slip)

This data is used only to activate and renew licences, issue receipts and contact the school about its use of the System. It is never sold, rented or used for advertising.

4. Use of data from Google APIs

PEHPEH's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. LINE and email notifications

If the school turns on LINE notifications, the System uses the school's own LINE Official Account. Linked LINE user IDs are stored in the school's own project. Email notifications are sent from the school's Google account. The provider does not receive this data.

6. Retention and deletion

The provider keeps the data in section 3 while the school uses the service and for no more than 2 years after the licence ends. The school can ask to view, correct or delete this data by email (below). The school can revoke the installer's access at any time at myaccount.google.com/permissions; web apps that are already installed keep working.

7. Changes to this policy

If this policy changes, the provider will update the effective date on this page and notify schools that use the service.
